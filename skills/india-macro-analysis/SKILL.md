# Indian Macro Research

## Shared evidence

Before collecting or interpreting inputs, read
[evidence and freshness](../india-research-core/references/evidence.md) and
[data access](../india-research-core/references/data-access.md). All sibling skills
are distributed with this suite. Load other procedures only when the task needs
them; apply them in the current session without assuming additional agents exist.

1. State cutoff and horizon. Read current RBI decisions/releases, official
   inflation/GDP/activity data, government budget/policy and relevant global
   central-bank/commodity releases. Preserve observation versus release dates,
   revisions, base-year changes and forecast versus realized data.
2. Assess real/nominal growth, inflation composition, rates/yields, liquidity,
   fiscal impulse, credit, external balance and currency using accessible series.
   Do not reconstruct missing releases from unverified headlines.
3. Map exposure-specific channels: demand, pricing, input costs, FX translation,
   funding, discount rates, credit quality and government/customer spending.
4. Distinguish data level from surprise; “above expectations” requires an actual
   pre-release forecast. Describe uncertainty and plausible policy responses.
5. Build scenarios and sector/company sensitivities over explicit horizons,
   supported by observed exposures. Include the next release calendar and what
   would change the outlook. Use `india-news-impact-analysis` for an event deep dive.

Deliver macro conditions and transmission, not a deterministic index prediction.
Historic correlations need economic interpretation and may fail across regimes.
