# Indian Technical Analysis

## Shared evidence

Before collecting or interpreting inputs, read
[evidence and freshness](../india-research-core/references/evidence.md) and
[data access](../india-research-core/references/data-access.md). All sibling skills
are distributed with this suite. Load other procedures only when the task needs
them; apply them in the current session without assuming additional agents exist.

Read [entry methods](../india-research-core/references/entry-methods.md) and
[calculation conventions](../india-research-core/references/calculations.md).

1. Verify symbol, exchange, timestamp, timeframes, corporate actions and consistent
   adjusted/raw OHLCV. Chart-only observations must identify chart date and are
   approximate; do not derive exact RSI/ATR from pixels.
2. Start weekly for structure and daily for timing; intraday analysis needs an
   appropriate feed. Identify trend, swings, zones, gaps, bases and invalidation.
3. Compute relevant SMA/EMA, Wilder RSI/ATR, MACD, Bollinger bands, volatility,
   volume context and relative strength against suitable sector/broad benchmarks.
   Use a parsimonious set; correlated indicators are not independent evidence.
4. Require volume, liquidity and closing confirmation when relevant. Describe
   false-breakout and gap risks. A chart pattern alone cannot establish valuation.
5. Give conditional continuation/pullback/breakout scenarios, key zones, triggers,
   invalidation and horizon. For reachability use dated history and market/sector
   evidence; missing fundamentals means a technical view only.

Deliver sourced chart interpretation and numerical table with parameter and
warm-up limitations. No automatic success probabilities for chart patterns.
